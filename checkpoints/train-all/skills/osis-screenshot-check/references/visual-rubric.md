# 视觉判断规则

## 总则

读取项目画像确定桥型后，按桥型规则判断截图。不读标准模板、不读用户提醒。

项目画像只用于确定桥型（等高/变高），不能用来解释视觉异常。

## 等高桥型判断规则

适用于：预制简支 T 梁、简支变连续小箱梁、预制简支空心板、现浇等截面箱梁。

等高桥型的梁高沿全跨不变。正视图中梁的轮廓应该是平滑连续的。

### 阶梯状台阶（section_step）

**核心原则：等高桥型看到阶梯就是错，不要用任何理由解释。**

阶梯可能出现在以下位置：
- **下缘**：梁底轮廓出现阶梯
- **上翼缘**：梁顶轮廓出现阶梯
- **腹板（中间部分）**：梁的垂直侧面出现阶梯

原因：等高桥型所有单元应使用相同或相近截面（墩顶加厚除外）。如果任何位置出现明显阶梯，说明 `_6_element.py` 中 nSec1/nSec2 映射有误。

**重要：不要用"项目画像说有 N 个截面"来解释阶梯。看到阶梯就是错，直接判定为错误。**

检查方法：打开 `_6_element.py`，找到异常区域的单元，检查其 nSec1 和 nSec2 是否与相邻单元连续。

### 上翼缘不连续

上翼缘出现断裂或错位 = **错误**。

检查方法：打开 `_4_section.py`，检查截面参数是否完整。

### 左右不对称

对称桥型出现左右不对称 = **错误**。

检查方法：打开 `_5_node.py`，检查节点坐标。

## 变高桥型判断规则

适用于：变截面悬浇连续梁、变截面连续刚构。

变高桥型的梁高从跨中到墩顶抛物线递增。正视图下缘是曲线，会有锯齿状台阶。

### 阶梯状台阶（section_step）

需要根据台阶高度差判断：

- 高度差 > 0.5m：可能错误，检查 `_6_element.py` 的 nSec1/nSec2 是否跳号。
- 高度差 < 0.3m：可能正常，是截面渐变的离散近似。
- 高度差 0.3-0.5m：需要结合截面数量和跨径判断。如果截面数量充足（跨径/截面数 < 5m），可能是正常；否则可能错误。

### 墩顶截面偏小

变高桥型墩顶应是最高截面。如果墩顶区域截面明显偏小 = **错误**。

检查方法：打开 `_4_section.py`，比较墩顶截面和跨中截面的梁高。

## 通用判断规则（所有桥型）

### 主体缺失

某段完全没有梁 = **错误**。

检查方法：打开 `_6_element.py`，检查单元是否完整。

### 裂缝或缝隙

主梁出现裂缝或缝隙 = **错误**。

检查方法：打开 `_4_section.py`，检查截面参数。

### 轴线折角

梁轴线出现明显折角 = **错误**。

检查方法：打开 `_5_node.py`，检查节点坐标是否平滑。

### 钢束穿出

钢束穿出截面轮廓 = **错误**。

检查方法：打开 `_2_property.py`，检查钢束线型坐标。

## 代码到视觉的完整映射

| 代码文件 | 参数 | 视觉影响 | 异常表现 |
|---|---|---|---|
| `_6_element.py` | nSec1/nSec2 | 截面过渡 | 阶梯状台阶 |
| `_4_section.py` | 截面参数 | 截面形状 | 形状异常、尺寸错误 |
| `_5_node.py` | 节点坐标 | 梁轴线位置 | 轴线折角、左右不对称 |
| `_2_property.py` | 钢束线型 | 钢束位置 | 钢束穿出截面 |
| `_7_boundary.py` | 支座约束 | 支座位置 | 支座位置异常 |
| `_4_section.py` | 桥墩截面（RECT） | 桥墩形状 | 桥墩缺失或形状错误 |

## 观察记录格式

写入 visual-observation-input.json：

```json
{
  "screening_result": "candidate",
  "observations": [
    {
      "observation_id": "obs-1",
      "region": "left_transition",
      "component": "main_girder",
      "phenomenon": "section_step",
      "boundary": "internal",
      "continuity_scope": "continuous_main_girder",
      "visibility": "clear",
      "description": "左侧主梁腹板出现清晰阶梯状台阶，高度差约 0.8m。T 梁为等高桥型，不应有阶梯。",
      "bbox_normalized": [0.1, 0.2, 0.3, 0.7],
      "bridge_type": "预制简支 T 梁",
      "check_file": "_6_element.py",
      "check_field": "nSec1/nSec2"
    }
  ]
}
```

无异常时：

```json
{
  "screening_result": "no_obvious_candidate",
  "observations": []
}
```

无法判断时（仅限变高桥型的边界情况）：

```json
{
  "screening_result": "unjudgeable",
  "observations": []
}
```
