# OSIS 视觉检查

## 流程

1. 截图。
2. 读项目画像，确定桥型。
3. 按桥型规则判断截图。
4. 有异常 → 读标准模板对比 → 按模板修复 → 复核。
5. 无异常 → 报告"未发现明显视觉异常"。

## 第一步：截图

先问用户要截哪个视角，然后执行：

```powershell
python -B "<skill_dir>/scripts/capture_canvas.py" capture-auto --run-dir <run_dir> --phase before --preset <视角>
```

视角选项：
- front（正视图）—— 默认，看主梁整体
- side（侧视图）—— 看梁高变化
- tendon（钢束图）—— 看钢束布置
- load（荷载图）—— 看荷载分布

截图后查看 `before-canvas.jpg`，不需要裁剪。

## 第二步：读项目画像

读取 `项目画像.md`，提取桥型和截面类型。

**重要：项目画像只用于确定桥型（等高/变高），不能用来解释视觉异常。看到阶梯就是错，不要用任何理由解释。**

桥型决定判断规则：

| 桥型 | 截面类型 | 梁高特征 |
|---|---|---|
| 预制简支 T 梁 | TGIRDER | 等高 |
| 简支变连续小箱梁 | SMALLBOX | 等高 |
| 预制简支空心板 | HOLLOWSLAB | 等高 |
| 现浇等截面箱梁 | CONVENTIONALBOX | 等高 |
| 变截面悬浇连续梁 | CONVENTIONALBOX | 变高 |
| 变截面连续刚构 | CONVENTIONALBOX | 变高 |

## 第三步：按桥型判断

### 等高桥型（T 梁 / 小箱梁 / 空心板 / 常规箱梁）

梁的轮廓应该是平滑连续的。出现阶梯 = 错误。

| 现象 | 判定 | 检查文件 |
|---|---|---|
| 任何位置阶梯状台阶 | **错误** | `_6_element.py` 的 nSec1/nSec2 |
| 上翼缘不连续 | **错误** | `_4_section.py` |
| 左右不对称 | **错误** | `_5_node.py` |
| 钢束穿出截面 | **错误** | `_2_property.py` |

### 变高桥型（悬浇箱梁 / 连续刚构）

下缘是曲线，会有锯齿。

| 现象 | 判定 | 检查文件 |
|---|---|---|
| 台阶高度差 > 0.5m | **可能错误** | `_6_element.py` 的 nSec1/nSec2 |
| 台阶高度差 < 0.3m | **可能正常** | — |
| 墩顶截面偏小 | **错误** | `_4_section.py` |
| 钢束穿出 | **错误** | `_2_property.py` |

### 通用（所有桥型）

| 现象 | 判定 | 检查文件 |
|---|---|---|
| 主体缺失 | **错误** | `_6_element.py` |
| 裂缝或缝隙 | **错误** | `_4_section.py` |
| 轴线折角 | **错误** | `_5_node.py` |

## 第四步：修复（模板对齐）

**核心原则：不要直接修改代码，而是读标准模板，对比差异，按模板修复。**

### 4.1 找到对应的标准模板

根据项目画像的桥型，在标准模板库中找到同类型模板：

```bash
# 标准模板位置：本次会话挂载的 skills 根目录下
<skills根目录>/osis-bridge-<桥型>/references/templates/<模板名>/prep/
# 用 read_skill / read_skill_reference 等技能工具读取，不要拼绝对路径
```

### 4.2 按异常类型对比

| 异常 | 对比文件 | 对比内容 |
|---|---|---|
| 阶梯状台阶 | `_6_element.py` | nSec1/nSec2 的渐变模式 |
| 截面形状异常 | `_4_section.py` | 截面参数和尺寸 |
| 轴线折角 | `_5_node.py` | 节点坐标间距 |
| 钢束穿出 | `_2_property.py` | 钢束线型坐标 |
| 支座位置异常 | `_7_boundary.py` | 支座约束位置 |
| 桥墩缺失/形状错误 | `_4_section.py` | 桥墩截面（RECT） |
| 主体缺失 | `_6_element.py` | 单元完整性 |

### 4.3 常见错误模式与修复

#### 阶梯状台阶（最常见）

**错误模式**：nSec1/nSec2 映射不连续，导致截面突变。

```python
# 用户项目（错误）：
Element 4: nSec1=1, nSec2=3  # 突变到截面 3
Element 5: nSec1=3, nSec2=1  # 又突变回截面 1

# 标准模板（正确）：
Element 4: nSec1=1, nSec2=1  # 保持截面 1
Element 5: nSec1=1, nSec2=1  # 保持截面 1
```

**修复方法**：按标准模板的 nSec1/nSec2 模式修改，保留渐变过渡。

#### 截面形状异常

**错误模式**：截面参数与标准模板不一致。

**修复方法**：按标准模板的截面参数修改。

#### 轴线折角

**错误模式**：节点坐标间距不均匀或不平滑。

**修复方法**：按标准模板的节点坐标间距修改。

#### 钢束穿出

**错误模式**：钢束线型坐标超出截面范围。

**修复方法**：按标准模板的钢束线型坐标修改。

### 4.4 修复流程

1. **读标准模板**：打开标准模板的对应 prep 文件
2. **对比差异**：逐行对比用户项目和标准模板的差异
3. **按模板修复**：只修改差异部分，保留用户项目的独有内容
4. **重建模型**：运行 `python -B <项目目录>/py/prep/main.py` 重建模型
5. **重新截图**：修复后重新截图复核

## 报告

- 无异常：报告"未发现明显视觉异常"，不得表述为"模型正确"。
- 有异常：报告异常现象、标准模板对比结果、已修复或未修复。
